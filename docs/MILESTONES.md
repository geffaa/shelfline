# Milestones — Shelfline

Sesuai arahan: tanpa estimasi waktu atau biaya. Urutan mengikuti ketergantungan; tiap milestone menghasilkan sesuatu yang bisa dicoba dan punya verifikasi. Fase: **P1** inti penjualan (M1–M8), **P2** operasi toko (M9–M19), **P3** pertumbuhan dan skala (M20–M24).

Urutan pemotongan bila perlu memangkas P1 (dari yang pertama dipotong): templat struk kustom → impor CSV katalog → profil pelanggan lanjutan → gabung pelanggan → Today realtime (ganti polling). Tidak dipotong: ledger, sinkron, sesi register, refund, offline.

Aturan umum: jalankan tes milestone berturut-turut beberapa kali sebelum menandai selesai (bug konkurensi sering baru muncul pada run ulang); temuan dari uji langsung dicatat di BREAKDOWN.
